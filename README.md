# Scotland Family Road Trip 2026

A responsive static web app for the 1–6 August 2026 Scotland family road trip.

## Files

- `index.html` – app structure
- `style.css` – responsive design
- `data.js` – trip data
- `app.js` – navigation, forms, routes, checklist, expenses and local saving

## Deploy with GitHub Pages

1. Upload all four files to the **root** of the repository.
2. Open **Settings → Pages**.
3. Choose **Deploy from a branch**.
4. Select **main** and **/(root)**.
5. Save and wait for deployment.

The site URL will normally be:

`https://YOUR-USERNAME.github.io/Scotland/`

## Important

Family details, checklist progress, expenses and notes are stored in the browser using `localStorage`. They do not sync between different devices.
